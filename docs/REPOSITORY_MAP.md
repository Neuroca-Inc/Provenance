# Repository Map

The repository is organized by evidence class, not by implementation project.

- `public/reach`: public release and reception evidence
- `git-history`: public commit evidence
- `chronology`: dependency chronology
- `historical`: historical manuscript evidence
- `methodology`: provenance-method lineage
- `records`: selected wording-sensitive historical records
- `source-index`: omitted-source custody
- `ledgers`: cross-surface indexes
