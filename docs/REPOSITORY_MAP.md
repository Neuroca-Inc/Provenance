# Repository Map

## `ledgers/`

Cross-project machine-readable indexes. These are the primary navigation layer.

## `chronology/`

Human narrative chronology. Chronology does not override claim status.

## `methodology/`

Research-method lineage.

### ORCHESTRA

Contains concrete preserved methodology sources. The v2.0 templates establish iterative research-evidence and publication-release package contracts. Later materials formalize research/evidence standards and exact ancestor custody.

### Cairn

Continuation point after ORCHESTRA. Exact first-artifact custody is still open and is intentionally not invented.

## `records/`

Selected research artifacts whose provenance value is high enough to include directly.

They remain typed:

- working note;
- dated baseline;
- correction record;
- run evidence;
- project-status snapshot.

## `hashes/`

The cryptographic custody layer. A private source can be provenance-relevant without its bytes being public.

## `source-index/`

Explains how selected material was mined from private/internal bundles.
