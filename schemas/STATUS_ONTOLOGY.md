# Status Ontology

| Status | Meaning |
|---|---|
| `CURRENT_CANON` | Controlling for its stated scope |
| `METHODOLOGY_SOURCE` | Governing/source artifact for research method |
| `RESEARCH_EVIDENCE` | Supports, attacks, reproduces, or falsifies a claim |
| `WORKING_NOTE` | Explicitly incomplete research object |
| `OPEN` | Burden remains unresolved |
| `HISTORICAL_BASELINE` | Dated exact state retained for comparison |
| `HISTORICAL_SOURCE` | Discovery/chronology evidence, not current authority |
| `SUPERSEDED` | Replaced for stated scope |
| `REJECTED` | Failed/withdrawn model or claim |
| `HASH_ANCHOR` | Source bytes withheld; hash retained |
| `REVIEW_REQUIRED` | Deliberate review required before promotion/public inclusion |
