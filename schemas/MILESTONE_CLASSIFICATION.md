# Git Milestone Classification

A commit is provenance-significant when it does at least one of the following:

- introduces a primitive, theorem, or hypothesis;
- changes the authority/custody boundary;
- closes or creates a proof burden;
- records a rejected model or correction;
- adds formal verification or decisive experiment evidence;
- begins a major implementation phase;
- establishes a dated baseline or retrospective;
- introduces provenance infrastructure;
- begins a downstream application whose chronology matters.

Large diffs and release tags are not automatically major milestones.
